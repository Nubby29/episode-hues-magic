# Re:Zero Chronicle

Build a dedicated Re:Zero (Starting Life in Another World) website featuring anime series and movies, novels (light novel and web novel guides), manga adaptations, and a rich character and lore wiki. Implement dynamic visual theming that shifts the design, color palette, and atmospheric accents to match the selected season or film (Season 1, Season 2 Sanctuary, Season 3 Priestella, Memory Snow, and Frozen Bond) while keeping a faithful fantasy aesthetic.
